# Networking Labs

Networking labs built in Cisco Packet Tracer, documented as write-ups. 
Each lab covers a certain problem subject, the configuration to solve the problem, and The troubleshooting of problems encountered along the way.

## Labs

|   | Lab | Topics |
|---|-----|--------|
| 1 | [VLANs, Trunking, Router-on-a-Stick](Lab1-VLANs_Trunking_Router-on-a-Stick/README.md) | VLANs, 802.1Q trunking, inter-VLAN routing |
| 2 | [NAT. Static, Dynamic, PAT](Lab2-NAT-static-dynamic-PAT/README.md) | Static NAT, Dynamic NAT, PAT (overloaded NAT), translation tables |
| 3 | [PPPoE, ISP Networking](Lab3-PPPoE_ISP_Networking/README.md) | PPPoE discovery/session, PPP CHAP authentication, virtual-template, BBA-groups |

## Structure

Each lab directory contains:
- `README.md` — the write-up (objective, config, verification, troubleshooting)
- `stages/` — Packet Tracer lab stages
- `images/` — source images
